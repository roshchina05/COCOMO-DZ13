## Что делает скрипт

Автоматизирует расчёт технико-экономического обоснования программного проекта по модели COCOMO II:

- **Уровень 1** — предварительное прототипирование (метод объектных точек)
- **Уровень 2** — предварительное проектирование (алгоритмическая модель)
- **Уровень 3** — постархитектурный уровень (с учётом ESLOC)
- **Стоимость персонала** (формула SC с поправочными коэффициентами)
- **Длительность проекта** (TDEV)
- **Модель Рэлея** — распределение трудоёмкости по месяцам
- **Модель Путмана** — независимая оценка трудоёмкости
- **HTML-отчёт** с интерактивными графиками (Chart.js)

## Установка

Требуется только Python 3.x — сторонних пакетов нет.

Проверить версию Python:
```bash
python --version
```

## Запуск

```bash
python cocomo_calculator.py
```

После запуска:
1. В терминале появится пошаговый вывод всех расчётов
2. В папке со скриптом создастся файл `report.html`
3. Откройте `report.html` в браузере — там таблицы и три интерактивных графика

## Структура файлов
cocomo_calculator.py   — основной скрипт расчёта и генерации отчёта
report.html            — HTML-отчёт (создаётся автоматически)
README.md              — описание проекта
